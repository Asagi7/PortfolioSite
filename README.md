# Portfolio Website

Coursera project: Setting Up Copilot / HTML / CSS / JavaScript / Developing and Testing with Copilot.

I used Copilot to scaffold semantic HTML, draft CSS grid + responsive rules, and generate JS for nav/filter/form. I reviewed and tested each suggestion manually.

## Files
- `index.html` - semantic structure (header/nav/main/section/article/footer)
- `styles.css` - styling + responsive `@media (max-width: 768px)`
- `script.js` - mobile nav, dark mode, project filter, form validation, back-to-top

## Deploy to GitHub Pages
1. New public repo, upload these 3 files, commit `Initial commit`.
2. Settings > Pages > Deploy from branch > main > Save.
3. Open `https://USERNAME.github.io/REPO/`.
